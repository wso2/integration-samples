# AI Chat Agent

## Description

This sample provides a conversational AI agent built with Ballerina. It uses the default WSO2 model provider and exposes a chat service that accepts user messages and returns responses from the agent.

The agent is a starting point that can be customized with a system prompt and tools for a specific use case.

## Usage Instructions

1. Open the sample in Ballerina Integrator.
2. Update the system prompt and add any required tools in `agents.bal`.
3. Run the integration using the **Run** button.
4. Use the chat interface to send messages to the agent and view its responses.

## Deploy on WSO2 Cloud

1. Deploy the integration on **WSO2 Cloud** as an **AI Agent**.
2. After the deployment is active, open the chat interface.
3. Send a message to start interacting with the agent.
