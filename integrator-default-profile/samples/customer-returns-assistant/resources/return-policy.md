# Customer Return Policy

## Return Window

Customers may request a resolution within **30 days** of the date the item was shipped. Requests
made more than 30 days after shipment are not eligible for an automatic exchange or refund and must go through
manual review.

## Eligible Resolutions

- **Exchange (replacement):** Offered when the item is faulty or defective, the order is within
  the 30-day return window, and a replacement unit is in stock.
- **Refund:** Offered when the item is faulty or defective, the order is within the 30-day return
  window, and no replacement is in stock.
- **Manual review:** Required when the order is outside the 30-day return window, the order or
  item cannot be found, the fault is unclear or disputed, or any other case that does not clearly
  match the exchange or refund criteria above.

## Notes

- This policy covers faulty or defective items only. Change-of-mind returns are not covered here
  and should be routed to manual review.
- Only one resolution should be recommended per request, with a clear reason referencing this
  policy.
